# 🎨 Mood Board Generator

An AI-powered mood board generator that analyzes the emotional content of photos and creates beautiful, themed mood boards.

## ✨ Live Demo

Try it now: [Mood Board Generator on Hugging Face](https://huggingface.co/spaces/alanie/mbg)

## 🎨 Features

- **AI Mood Analysis**: Automatically detects the emotional tone of uploaded images
- **Multiple Themes**: Choose from 8 different aesthetic themes
- **Visual Styles**: Apply various color styles (Vibrant, Muted, Pastel, etc.)
- **Customizable**: Adjust color intensity to match your vision
- **Instant Generation**: Get your mood board in seconds

## 🚀 Quick Start

### Online (Hugging Face Spaces)

Visit our live demo: [https://huggingface.co/spaces/alanie/mbg](https://huggingface.co/spaces/alanie/mbg)

### Local Installation

```bash
# Clone the repository
git clone https://github.com/devigngo2026/mood-board-generator.git
cd mood-board-generator

# Install dependencies
pip install -r requirements.txt

# Run the app
python app.py
```

Then open your browser to `http://localhost:7860`

## 📦 Requirements

- Python 3.9+
- gradio >= 4.0.0
- Pillow >= 10.0.0
- numpy >= 1.24.0

See `requirements.txt` for full dependencies.

## 🎯 How It Works

1. **Upload**: Choose a photo that represents your mood or vision
2. **Configure**: Select a theme, style, and color intensity
3. **Generate**: Click the button and let AI create your mood board
4. **Download**: Save and share your creation
