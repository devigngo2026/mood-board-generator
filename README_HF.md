# Mood Board Generator

An AI-powered mood board generator that analyzes the emotional content of photos and creates beautiful, themed mood boards.

## Features

- 🎨 AI-powered mood analysis
- 🌈 8 different themes
- 🎭 Multiple visual styles
- ⚡ Instant generation
- 📱 Mobile-friendly interface

## How to Use

1. Upload a photo
2. Select your preferred theme and style
3. Adjust color intensity
4. Click "Generate Mood Board"
5. Download and share your creation!

## Technology

Built with Gradio and deployed on Hugging Face Spaces.
